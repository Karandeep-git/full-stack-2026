CSS Color Systems

1. Named Colors

This text uses the anmed color "red" - simple English word, browser knows it.

This uses "tomato" - a slightly orange-red. There are 140 named colors in CSS.

This div has a "steelblue" background and "white text" - both named colors.

2. Hex Colors

This text is colored using a hex code - #E74C37 - a professional crimson red.

This div uses hex code #2C3E50 as background - a deep dark blue-grey used by many professional apps.
Hex shorthand: #333 is the same as #333333 - dark grey. Only works when both charcters in each pair are identical.

3. RGB Colors

This text uses rgb(41, 128, 185) - a clean medium blue defined by red=41, green=128, blue=185.

This background uses rgb(39, 174, 96) - Groww-style green. Full control over each color channel.

4. RGBA - RGBA with Transparency

rgba background at 0.9 opacity - almost fully solid.
rgba background at 0.5 opacity - half transparent, background show through
rgba background at 0.2 opacity - mostly transparent

This text color itself uses rgba - rgba(231, 76, 60, 0.6) - a semi-transparent red text.

5. HSL Colors

hsl(0, 100%, 50%) - Pure red. Hue=0 means red on the color wheel.
hsl(120, 100%, 35%) - Deep green. Hue=120 means green on the color wheel.
hsl(240, 100%, 60%) - Bright blue. Hue=240 means blue on the color wheel.
hsl(240, 30%, 60%) - Muted blue. Lower saturation = more grey mixed in.
hsl(240, 100%, 85%) - Light blue. Higher lightness = closer to white.

6. The opacity Property

opacity: 1.0 - fully visible. Text AND background are fully solid.
opacity: 0.5 - the ENTIRE element is 50% transparent. Notice the text is also faded - this is different from rgba.
opacity: 0.2 - barely visible. Everything inside is faded.
