Text and Font Properties in CSS

1. Font-family

This text uses a SERIF font - "Playfair Display" from Google Fonts. Serif fonts have small decoractive strokes at the ends of letters. Used for elegant, editiorial, or classic designs.

This text uses a SANS-SERIF font - "Inter" from Google Fonts. Sans-serif fonts have clean, straight edges with no decorative strokes. Used for modern UI, apps and dashboards. Most websites use sans-serif.

This text uses a MONOSPACE font - "Cuourier New". Every character is exactly the same width. Used for code editiors, terminals and displaying code.

This text uses a font stack - Arial is tried first, then Helvetica Neue, then Helvetica, then ay sans-serif the system has. This is professional way to ensure your design works on every device.

2. Font-size

font-size: 12px - very small, used for footnotes and captions

font-size: 16px - the browser default body text size

font-size: 20px - slightly larger, good for lead paragraphs

font-size: 28px - heading-level size

font-size: 48px - hero/display text

font-size: 18px - fixed pixel size, never changes

font-size: 1.125rem - relative to the root (html) font size

font-size: 1.2em - relative to the PARENT element's font-size

font-size: 120% - 120% of the parent element's font size

font-weight: 100 - Thin (requires a font that supports it)

font-weight: 300 - Light

font-weight: 400 - Normal (same as "normal")

font-weight: 600 - Semi-Bold

font-weight: 700 - Bold (same as "bold")

font-weight: 900 - Black / Extra Bold

4. font-style

font-style: normal - upright text, this is the default

font-style: italic - slandted text, used for emphasis, quotes or captions

5. line-height

line-height: 1.0 - Too tight:

This paragraph has very tight line spacing. When text lines are this close together, the human eye struggles to track from the end of one line to the start of the next. Reading beocmes slow and tiring.

line-height: 1.5 Comfortable (recommended):

This paragraph has the recommended line height. The 1.5 value means each line's box is 1.5 times the font size tall. This gives text room to breathe and makes long paragraphs much more comfortable to read.

line-height: 2.2 - Too loose:

This paragraph has very loose line spacing. The lines feel disconnected from each other and reading becomes awkward because the eye has too much empty space to jump across between lines.

Single line vertically centered using line-height equal to container height

6. text-align

text-align: left - text starts from the left edge. This is the default for left-to-right languages like English. Best for body text because the eye always knows where the next line starts.

text-align: center - text is centered horizontally. Best for headings, short titles, and hero text. Avoid centering long paragraphs - hard to read.

text-align: right - text starts from right edge. Used for prices in tables, timestamps and right-to-left language support.

text-align: justify - both left and right edges are perfectly straight, like a newspaper or book. The browser adds extra space between words to achieve this. Be careful - it can create awkward gaps int short lines or narrow containers.

7. letter-spacing

letter-spacing: 0 - default, no extra spacing between characters

letter-spacing: 1px - very slight brathing room between characters

letter-spacing: 3px - noticeable spacing, modern UI feel

letter-spacing: 6px - wide spacing, often used for uppercase labels

8. text-decoration

text-decoration: none - removes underline. Most commonly used on anchor tas to remove their default underline.

text-decoration: overline - adds a line above the text

9. text-transform

text-transform: none - text displays exactly as typed in HTML

text-transform: uppercase - forces all letters to UPPERCASE

text-transform: lowercase - forces ALL LETTERS to lowercase

text-transform: capitalize - capitalizes The First Letter Of Each World
